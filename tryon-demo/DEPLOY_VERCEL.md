# Деплой демо на Vercel

Самый быстрый вариант для защиты: Vercel Hobby + существующий API Hugging Face. GPU в Yandex Cloud не нужен.

## 1. Создать проект

1. Открыть https://vercel.com/new и импортировать `reyssxxx/business-studia-ozon`.
2. В настройках проекта указать **Root Directory**: `tryon-demo`.
3. Framework Preset: **Vite** (обычно определяется автоматически).
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Install Command: `npm install`.
7. Нажать Deploy.

Каталог `api/` находится внутри Root Directory, поэтому Vercel автоматически поднимет `POST /api/tryon` как Function.

## 2. Подключить бесплатную генерацию

В Vercel → Project → Settings → Environment Variables добавить:

- `HF_TOKEN` — личный Hugging Face token с правом Read. Создать: https://huggingface.co/settings/tokens
- `TRYON_PROVIDER` — `hf`
- `MAX_GENERATIONS_PER_DAY` — `20`
- `MAX_GENERATIONS_PER_HOUR_PER_IP` — `10`

После добавления переменных сделать **Redeploy** последнего deployment.

Не вставлять токен в исходники, GitHub или публичный чат. Добавлять его только в Vercel Environment Variables.

Опционально можно добавить `POLLINATIONS_KEY` как резервный API-ключ. При лимите/перегрузке Hugging Face backend попробует Pollinations; это другая модель, и точность сохранения одежды может быть ниже.

## 3. Проверить

Открыть адрес Vercel на телефоне:

- Главная страница должна загрузиться.
- `/api/tryon` должен вернуть JSON со статусом и выбранным провайдером.
- Сделать одну тестовую примерку с небольшими изображениями.

Перед защитой проверить генерацию заранее: бесплатные Hugging Face Spaces могут просыпаться, ставить запросы в очередь и ограничивать GPU-время. У бесплатного аккаунта ZeroGPU сейчас 5 минут GPU-времени в сутки; у анонимных запросов — 2 минуты. Квота привязана к аккаунту, чей токен используется сервером. Поэтому 20 генераций не гарантированы в бесплатном режиме — фактическое время зависит от модели и очереди.

Для защиты лучше заранее прогнать тесты, сохранить пару удачных результатов и иметь их под рукой как резерв, если Space временно недоступен.

## Важно

- Не разворачивать модель на Yandex Cloud: для этой демонстрации это дольше и не требуется.
- Не загружать реальные личные фотографии без согласия человека.
- Vercel Hobby подходит для учебного некоммерческого демо; проверьте актуальные условия своего аккаунта.
