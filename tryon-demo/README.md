# Примерочная: демо для защиты (кейс Ozon, ИН-1)

Веб-прототип в рамке телефона: каталог → карточка → примерка по фото или по росту и весу → размер → «Собрать образ» → корзина → «Аналитика пилота».

## Запуск

```bash
npm install
cp .env.example .env   # вписать HF_TOKEN (бесплатно) или FAL_KEY
npm run dev
```

Бесплатная генерация работает через Hugging Face Spaces. Для защиты добавьте HF_TOKEN: без токена дневная GPU-квота особенно мала. Инструкция по публикации сайта: [DEPLOY_VERCEL.md](DEPLOY_VERCEL.md).

## Как устроено

Нейросети, структура кода и целевая схема описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## Картинки

- Фото товаров и аватары лежат в `src/assets/garments` и `src/assets/avatars`.
- Сгенерировать недостающие: `node scripts/gen-assets.mjs` (нужен `HF_TOKEN` в `.env`).
- Свои фото: положить файл `<id>.jpg` или `<id>.webp` в ту же папку, он заменит временный рисунок.
