# Виртуальная примерка одежды: кейс Ozon (ИН-1)

Учебный проект «Бизнес-студии»: инициатива виртуальной примерки одежды и кросс-села «Собрать образ» для маркетплейса.
Концепт команды, не связан с Ozon официально.

## Что внутри

| Папка / файл | Что это |
|---|---|
| [`tryon-demo/`](tryon-demo/) | Рабочий MVP: веб-приложение в стиле маркетплейса с живой генерацией примерки нейросетью, подбором образов и гардеробом. Подробности в [README](tryon-demo/README.md) и [ARCHITECTURE](tryon-demo/ARCHITECTURE.md). |
| [`model/`](model/) | Скрипты финансовой модели (Python): расчёт сценариев и сборка Excel. |
| `Ozon_проект_ДЗ2.3.xlsx` | Финансовая модель: три сценария, чувствительность, пороги пилота. |
| [`MVP_демо_план.md`](MVP_демо_план.md) | План демонстрации MVP на защите. |

## Быстрый старт

```bash
cd tryon-demo
npm install
cp .env.example .env   # вписать HF_TOKEN (бесплатно) и при желании POLLINATIONS_KEY или FAL_KEY
npm run dev
```

Без ключей приложение работает, но бесплатная квота нейросети почти нулевая.
